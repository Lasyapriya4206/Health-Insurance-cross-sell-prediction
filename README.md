# 🚗 Health Insurance Cross-Sell Prediction

This project predicts whether existing health insurance customers are likely to buy a vehicle insurance policy. The workflow includes data preprocessing, model training, evaluation, and deployment using Streamlit.

## 🔍 Project Overview
- Load and clean customer dataset  
- Preprocess features (scaling & encoding)  
- Train a Random Forest classifier  
- Evaluate using accuracy and ROC curve  
- Deploy a user-friendly Streamlit prediction app

## 📁 Project Structure
- `src/` – preprocessing & modeling scripts  
- `app/` – Streamlit user interface  
- `models/` – saved trained model  
- `results/` – accuracy & ROC curve  
- `notebooks/` – full ML pipeline notebook  

## 📊 Model Performance
- ~87% accuracy  
- Good classification performance with ROC curve visualization  

This project helps insurance companies identify customers who are likely to buy additional policies.
